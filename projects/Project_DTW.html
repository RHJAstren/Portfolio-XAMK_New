What is Drive to Work (DTW)

Drive to work is a rage game that is about scaling up a shortcut for the MC to make it to work on time. The basis for this game is the car controls. We wanted to create satisfying driving mechanics for the game, similar to Mario Kart, where the player is able to boost after a certain amount of drifting is done. A simple game that is sure to succeed.

What I worked on

I am mainly programming the entire functionality of the game. I worked on the UI as well as the driving mechanics of the game. The mechanics still need some time to properly be of use though. I also created the UI for the game and we plan on the art to be similar to a 90s cartoon type animation.
